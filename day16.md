Day 16 - Git Branching

Today I learned:
- What a branch is and why it's used (working on something new without affecting the main code)
- How to create a new branch (git checkout -b)
- How to switch between branches (git checkout)
- How to merge a branch into main (git merge)
- How to delete a branch (git branch -d / -D)
- Understood that everything I did from Day 1 to Day 15 was actually happening on the main branch, since Git creates it automatically by default

Confusing part: Understanding exactly what gets pushed to GitHub when merging branches, and realizing that a branch deleted without merging loses its changes completely.
