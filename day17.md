Day 17 - CI/CD Basics with GitHub Actions

Today I learned:
- What CI/CD means (Continuous Integration/Continuous Deployment)
- What GitHub Actions is and why companies use it
- How to create a workflow file (.github/workflows folder)
- Basic YAML structure for a workflow (name, on, jobs, runs-on, steps, run)
- Debugged a real error (typo: run-on instead of runs-on) and fixed it
- Understood that this same process (push -> automatic check -> fix if failed) is used in real companies at a much larger scale
