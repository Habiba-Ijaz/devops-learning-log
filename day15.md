Day 15 - Pushing Images to Docker Hub

Today I learned:
- How to log in to Docker Hub from terminal (docker login)
- The difference between Ubuntu password and Docker Hub password/token
- How to create a Personal Access Token (PAT) with Read & Write permissions
- How to tag an image with my username (docker tag)
- How to push an image to Docker Hub (docker push)
- How to delete images locally (docker rmi, docker image prune)

Confusing part: Understanding why the first token didn't work (it only had Read permission, not Write), and remembering the "." at the end of the docker build command
